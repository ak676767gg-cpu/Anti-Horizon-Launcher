# Security

## Reporting a problem

If you find a security problem in the Anti Horizon Launcher (anything that could harm players, their Microsoft
accounts, their computers or their worlds), please report it **privately**, not in a public issue:

- Use **[Report a vulnerability](https://github.com/ak676767gg-cpu/Anti-Horizon-Launcher/security/advisories/new)**
  on the repository's Security tab, or
- the contact page at <https://anti-horizon.com/contact/>.

Say what you found, which version it affects, and how to reproduce it if you can. You'll get a reply within a few
days, and a fix as soon as possible. Once it's fixed and released, you're welcome to be credited.

## Fake copies

The only official places to get the launcher are <https://anti-horizon.com> and this repository's releases. Official copies update themselves
only with updates signed by Anti-Horizon, and only official copies can sign in with the launcher's Microsoft app.
If you find a lookalike, please report it through the contact page above.

## What the launcher can access

See [Why you can trust it](README.md#why-you-can-trust-it): you sign in on Microsoft's own page, your sign-in stays
on your computer where only you can read it, and it talks only to the services listed there.
