# Security

If you find a security problem in the Anti Horizon Launcher or the Anti-Horizon client (anything that could harm
players, their Microsoft accounts, their computers or their worlds), please report it **privately**, not in a public
issue:

- Use **[Report a vulnerability](https://github.com/ak676767gg-cpu/Anti-Horizon-Launcher/security/advisories/new)**
  on this repository's Security tab, or
- the contact page at <https://anti-horizon.com/play/contact.html>.

Say what you found, which version it affects, and how to reproduce it if you can. You'll get a reply within a few
days, and a fix as soon as possible. Once it's fixed and released, you're welcome to be credited.

The only official places to get them are <https://anti-horizon.com> and this repository. More detail is in
[launcher/SECURITY.md](launcher/SECURITY.md) and [client/SECURITY.md](client/SECURITY.md).
